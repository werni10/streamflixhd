DEPLOYMENT CHECKLIST
════════════════════

Prerequisites:
  ✓ Supabase account (free tier works)
  ✓ Vercel account (free tier works)
  ✓ GitHub account

Setup Steps:
  1. Clone repo to GitHub
  2. Create Supabase project
  3. Get DATABASE_URL from Supabase
  4. Import to Vercel:
     → Select GitHub repo
     → Add environment variables:
        - DATABASE_URL
        - NEXTAUTH_SECRET
        - NEXTAUTH_URL
  5. Deploy
  6. Run migrations:
     npx prisma migrate deploy
  7. Seed data:
     npm run db:seed

Result:
  ✓ Site live at yourproject.vercel.app
  ✓ Admin at /admin/login
  ✓ Default creds: admin / admin123 (change after login)
  ✓ File uploads work via Vercel Blob
  ✓ Database on Supabase
  ✓ Global CDN for images
