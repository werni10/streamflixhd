═══════════════════════════════════════════════════════════════════
  AUTHENTICATION FLOW
═══════════════════════════════════════════════════════════════════

1. User visits /admin/login
2. Submits username + password
3. NextAuth verifies credentials against admins table
4. Password verified with bcrypt.compare()
5. JWT session created (httpOnly cookie)
6. Redirect to /admin/dashboard
7. All admin pages check session middleware
8. Unauthenticated visitors redirected to /admin/login
9. Logout clears session
