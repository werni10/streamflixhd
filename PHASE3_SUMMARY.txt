═══════════════════════════════════════════════════════════════════
  API ENDPOINTS (NEW)
═══════════════════════════════════════════════════════════════════

POST   /api/upload                      Upload image (auth required)
                                        Returns: { url, filename }

GET    /api/admin/settings              Get all settings (auth required)
                                        Returns: { key1: value1, ... }

POST   /api/admin/settings              Create/update setting (auth required)
                                        Body: { key, value }

POST   /api/admin/profile/change-password  Change password (auth required)
                                        Body: { currentPassword, newPassword }

  SETUP FOR LOCAL DEVELOPMENT
═══════════════════════════════════════════════════════════════════

1. Get Vercel Blob Token:
   → Create Vercel account (if not done)
   → Go to project settings → Storage → Blob
   → Create token → Copy to clipboard

2. Add to .env.local:
   BLOB_READ_WRITE_TOKEN=your_token_here

3. Run:
   npm run dev

  FILE UPLOAD FLOW (TECHNICAL)
═══════════════════════════════════════════════════════════════════

1. User selects image in <input type="file">
2. JavaScript preview shows immediately (FileReader API)
3. Form submit:
   → POST /api/upload { file }
   → Vercel Blob receives file
   → Generates public URL
   → Returns { url, filename }
4. URL stored in database (content.photo column)
5. Image loads from Vercel CDN when displayed

Benefits:
  ✓ No file size limits on serverless function
  ✓ Automatic CDN distribution
  ✓ Easy to manage (Vercel dashboard)
  ✓ Scales automatically
  ✓ No need for separate storage service

═══════════════════════════════════════════════════════════════════
  SECURITY & VALIDATION
═══════════════════════════════════════════════════════════════════

File Upload:
  ✓ Auth check (NextAuth session required)
  ✓ File type validation (image/* only)
  ✓ File size limit (5MB max)
  ✓ Public URL only (images readable, not editable)

Password Change:
  ✓ Auth check (admin session required)
  ✓ Current password verified (bcrypt.compare)
  ✓ New password != old password
  ✓ Min length 6 characters
  ✓ Session invalidated after change (force re-login)

Settings:
  ✓ Auth check required
  ✓ No validation (stores any string)
  ✓ Can be added/updated freely

  PRODUCTION DEPLOYMENT
═══════════════════════════════════════════════════════════════════

When deploying to Vercel:

1. Vercel automatically provides BLOB_READ_WRITE_TOKEN
   → No manual setup needed

2. Add to Vercel environment variables (if using external service):
   → DATABASE_URL (Supabase connection)
   → NEXTAUTH_SECRET
   → NEXTAUTH_URL

3. Push to GitHub:
   $ git add .
   $ git commit -m "Phase 3: File uploads & settings"
   $ git push

4. Vercel auto-deploys:
   → File uploads work immediately
   → Images served from global CDN
   → Production-ready
